/speckit.constitution 這是 obsidian 筆記軟體的外掛開發的環境，請遵守 https://docs.obsidian.md/Plugins/Getting+started/Build+a+plugin 開發規範，並且以 https://github.com/obsidianmd/obsidian-sample-plugin 作為外掛開發基礎。

開發原則：
1. 請遵守 https://docs.obsidian.md/Plugins/Getting+started/Build+a+plugin 開發規範
2. 使用 https://github.com/obsidianmd/obsidian-sample-plugin 作為外掛開發基礎
3. 遵守 typescript 語言開發， NodeJS 版本至少為 v16 以上
4. 使用 eslint 提高程式碼品質
5. 以 https://github.com/obsidianmd/obsidian-api/blob/master/obsidian.d.ts 作為 obsidian API 與風格規範

測試與文件原則：
1. 功能項目實作前後並且實作單元測試與整合測試，確認功能正確。
2. 功能實作後請實作 changelog 描述：實作目的、實現方式、結果與建議事項。參考指南作為實作原則：.github/instructions/changelog.instructions.md
3. 每次功能時做完，請自動紀錄版本，呼叫`git-auto-push -a` 自動保存更新
4. 確保實作不需要保存任何金鑰與密鑰內容， git 更新以前請檢查確認
